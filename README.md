# 🍽️ Zomato Order & Restaurant Analysis – Power BI Dashboard

I’m excited to share my latest Data Analytics project: **Zomato Order & Restaurant Analysis using Power BI!**

In this project, I analyzed Zomato's restaurant and order datasets to understand restaurant performance, customer preferences, sales trends, and business insights.

### 🎯 Project Objectives
- Analyze the number of restaurants across different cities.
- Understand order distribution by city.
- Track order amount trends over time.
- Analyze factors affecting restaurant ratings.
- Identify the Top 5 restaurants by total sales.
- Explore revenue distribution across different areas.
